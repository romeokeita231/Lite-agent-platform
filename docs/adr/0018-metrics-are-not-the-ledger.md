# 指标不是账本

Status: accepted

Prometheus 只回答"系统健康吗"，`tenant_id` 不进指标标签；"谁用了多少"从账本查（`/v1/tenants/{id}/usage`）。

## Consequences

- 避免标签基数爆破：租户数 × 模型 × 路由标签 × 状态，series 数量随租户数线性失控。Prometheus 会先变慢，再变贵，最后被运维关掉。
- 更要紧的是口径：同一份数字出现在两处就迟早对不上，而其中一处要用来算钱。分工写死——**指标答健康，账本答用量**。
- 指标清单按"平台自己会问的问题"倒推，不按惯例凑数：Run 状态分布、Step 重试次数、fallback 触发次数、模型调用延迟分布、工具调用失败率、上下文 token 与裁剪丢弃量、单租户并发占用。
