# Fallback 只吃可重试的错误，且对调用方可见

Status: accepted

原设计写"模型调用失败或超限时自动切换备用模型，对调用方透明"，但没定义哪些错误该换、重试与 fallback 怎么叠加。定三条：只有 429 / 5xx / 超时触发 fallback（400、401 换谁都没用）；每个模型只尝试一次，整条 fallback 链共享一个总预算；响应里回显实际生效的模型与 fallback 链。

## Consequences

- 退避重试只在一个地方做——Run 的 Step 重试。模型网关不再自己退避，否则两层退避互相掩盖，超时预算也算不清。
- "对调用方透明"改写为"调用方无需改代码，但要能解释结果"：同一个 Run 里模型可能换过，调用方必须能从响应里看出来。
- `model_call_logs.fallback_from` 只记上一跳，完整链路从 Trace 读。两处不重复存储，也不允许多处各记一半。
